# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Build/Run Commands
- Run server: `python3 server.py`
- Add display to path: `export PATH=$PATH:/path/to/CS_Store`
- Launch application: `display`

## Dependencies
- Install dependencies: `pip install -r requirements.txt`

## Code Style Guidelines
- Use PEP 8 for Python code formatting
- Import order: standard library -> third-party -> local
- Use descriptive variable names (snake_case for Python)
- Error handling: Use try/except blocks with specific exceptions
- Include logging for errors and important operations
- Maintain consistent indentation (4 spaces for Python)
- Document code with docstrings for functions and classes
- Follow existing patterns for HTML/CSS/JS code
- Maintain consistent theme styling conventions in CSS
